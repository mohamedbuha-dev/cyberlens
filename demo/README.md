# حزمة الدِيمو — CyberLens

عيّنات جاهزة وأدوات لعرض المنصة أمام اللجنة.

## المحتويات
- `samples/1_safe.eml` — رسالة سليمة → **منخفضة (0%)**
- `samples/2_suspicious.eml` — لغة استعجالية + رابط مختصر → **متوسطة (30%)**
- `samples/3_dangerous.eml` — انتحال PayPal + طلب كلمة مرور + رابط IP + مرفق `invoice.pdf.exe` → **حرجة (100%)**
- `inject_samples.py` — يحقن العيّنات في صندوق البريد المُراقَب (للدِيمو التلقائي)
- `test_raw.sh` — يعرض درجات العيّنات فورًا بدون Gmail (للتجربة/البروفة)

## سيناريو العرض (تلقائي عبر البوابة)

1. تأكد أن `.env` معبّأ ببيانات Gmail التجريبي، وأن المنصة شغّالة:
   ```bash
   docker compose up --build -d
   ```
2. افتح اللوحة: **http://localhost:8081**
3. احقن العيّنات:
   ```bash
   python3 demo/inject_samples.py
   ```
4. خلال ثوانٍ (حسب `IMAP_POLL_INTERVAL`) تظهر الرسائل الثلاث في اللوحة تلقائيًا،
   كلٌّ بشريط ملوّن ووميض عند وصولها — بدون أي إدخال يدوي.

## بروفة سريعة بدون Gmail

للتأكد من الدرجات قبل العرض (يستدعي الـ API مباشرة):
```bash
bash demo/test_raw.sh
```
> ملاحظة: هذا السكربت يحفظ نتائجه في السجل أيضًا. لتصفير السجل قبل العرض:
> `docker compose down -v && docker compose up --build -d` (يمسح قاعدة البيانات).

## نقاط تستحق الذكر أمام اللجنة
- التحليل نصي/بنيوي بالكامل — لا يُفتح أي رابط أو مرفق فعليًا.
- نفس محرّك التحليل يخدم: الفورم اليدوي، نقطة `/api/analyze/raw`، وبوابة IMAP.
- البوابة تعمل كخيط خلفي داخل نفس الحاوية → كل شيء بـ `docker compose up`.
